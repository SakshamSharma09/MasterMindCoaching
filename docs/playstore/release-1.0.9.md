# MasterMind Coaching Classes 1.0.9

## Google Play release notes

Improved student records, attendance follow-ups, Finance, parent access, downloads, and Android navigation.

- Correct parent names, current school, and enrollment dates
- Accurate attendance and pending-fee dashboard figures
- WhatsApp absence messages include India country code and 3–6 PM class time
- Simpler fee entry and monthly teacher salary tracking
- Secure parent password invitation links
- Improved template and document downloads
- Safer navigation around Android status bars
- Collapsible Paper and Notes prompt generators

## Rollout

1. Upload `versionCode 10`, version `1.0.9`, to Production.
2. Start at 10%.
3. Review crash, ANR, login, invitation, and API health after 24–48 hours.
4. Increase to 50%, observe again, then complete at 100%.

## Reviewer access instructions

1. Open the app.
2. Select **Mobile Password**.
3. Enter the dedicated Parent reviewer mobile and password recorded in Play Console.
4. The account is reusable, has no OTP or location dependency, and is linked only to a synthetic student.

Do not store reviewer credentials in this repository.
